# 第二大腦（空白模板）

這不是存筆記的地方，是**逼你講出來**的地方。講不清楚＝還不懂。
AI 只負責**問問題、考試**，不幫你寫卡片。

搭配 [Claude Code](https://claude.com/claude-code)（或其他會讀 `AGENTS.md`、支援 Agent Skills 的 agent）＋ [Obsidian](https://obsidian.md) 使用。

## 開始用（3 步）

1. 按右上角 **Use this template → Create a new repository**，建一份**自己的**（建議設成 Private，裡面會是你的想法）。
2. clone 下來：`git clone <你的 repo>`，用 Obsidian 打開這個資料夾（想看卡片樣式：設定 → 外觀 → CSS 片段 → 打開 `second-brain`）。
3. 在這個資料夾開 Claude Code：`cd <資料夾> && claude`，然後說 `/learn <你想學的東西>`。

## 一張圖看懂

```
 想法、錄音                     書、文章、論文
     │                               │
     ▼                               ▼
  inbox/ ── /inbox 分類 ──┐     /add（先講為什麼存）
                          ▼          │
                 index.md 排隊區 ◀───┘
                          ▼
                /learn（約 15 分鐘）
     你先講 → 被追問 → 白話講給外行人聽 → 應用題
                          ▼
           cards/<概念>.md ← 卡片內容是你的原話
                          ▼
              /review：第 1、7、30 天各考一次
```

## 四個指令

| 說 | 什麼時候 | AI 會做什麼 |
|---|---|---|
| `/inbox` | 錄音或想法累積了一些 | 分成「待學、來源、觀點、待辦」，**先給你看分類表，你確認了才寫進去** |
| `/add` | 想收一本書或一篇文章 | 先問你為什麼存，沒有答案就不收。文章存全文 |
| `/learn <主題>` | 有 15 分鐘，想學一個東西 | 蘇格拉底追問 → 費曼講解 → 應用題 → 用你的原話存成卡片 |
| `/review` | 每天，或有卡片到期時 | 只考不給看，考完才讓你對照原本的卡片 |
| 「進度」 | 想知道學到哪 | 列出進行中、今天到期的卡、排隊中的主題 |

## 三種卡，三種「學會」

| 卡片類型 | 例子 | 怎樣算學會 | 多久考一次 |
|---|---|---|---|
| **概念** | 鷹派鴿派、複利 | 講給外行人聽得懂 ＋ 答對沒看過的題目 | 第 1、7、30 天，都過了就是 `passed` |
| **技能** | 寫回測、看財報 | 講得出步驟 ＋ **真的做過，留下紀錄**（放 `practice/`） | 第 7、30 天問「最近有做嗎？拿紀錄來」 |
| **觀點** | 交易心法、人生觀 | 被追問後還站得住 ＋ 寫下「什麼事會讓我改變想法」 | 每 90 天問一次 |

## AI 答應你的事

1. **不寫卡片內文。** 卡片上每一個字都是你講的，AI 只修錯字。
2. **不先給答案。** 同一個點卡住兩次，才給一個方向提示。
   - 你只是隨口問「X 是什麼」，AI 會先問：要快速答案，還是要好好學？
   - 卡到很煩，說「**直接告訴我**」，那一點就直接講。之後會換個角度再考你一次。
   - 剛提示完你馬上答對，不算過。要隔一題再自己講一次。
3. **判斷對錯要附出處。** 找不到就說「未確認」。
4. **兩個來源說法打架，不幫你選**，會問你：「A 這樣說、B 那樣說，你怎麼看？」

## 資料夾

| 資料夾 | 放什麼 |
|---|---|
| `inbox/` | 隨手錄音、想法（一段一檔） |
| `raw/` | 書、文章（全文）、論文 |
| `cards/` | 原子卡，一張一個概念，全部平放 |
| `maps/` | 領域地圖，把卡片串起來 |
| `sessions/` | 每次問答的紀錄（停在哪、下一步） |
| `practice/` | 技能的實作紀錄 |
| `index.md` | 總目錄：進行中、下一個要學、待讀來源 |

給 AI 看的完整規則在 `AGENTS.md`，指令在 `.claude/skills/`。想改規則就直接改這兩個地方。

## 節奏

1. 一次 15 分鐘，只碰一個主題。
2. 先考再學：有到期的卡就先 `/review`。
3. 同時進行的主題最多 3 條。
4. 每次結束，AI 會 commit 並 push，你的大腦會留在 GitHub 上。

架構參考 Zettelkasten、Andy Matuschak 的 evergreen notes、MOC 地圖頁。
