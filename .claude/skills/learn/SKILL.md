# /learn <主題>

一次約 15 分鐘。先讀 `AGENTS.md` 的鐵則。一次只問一個問題，等使用者回答。

## 開課前先確認

使用者沒有打 `/learn`，只是問「X 是什麼」「X 該怎麼定義」→ 先問一句：
「要快速答案，還是要好好學（約 15 分鐘，會存成卡）？」
- 快速答案 → 照鐵則 3 附出處直接回答，最後問「要不要之後 `/learn` 它？」，要就加進 `index.md`「下一個要學」。
- 好好學 → 從第 0 步開始。

## 隨時可用：「直接告訴我」

使用者說「直接告訴我」「不想猜了」→ 只對**這一個點**直接講答案（附出處），其他點照常用問的。
- session 紀錄寫「<這個點>：使用者要求直接講」。
- 這個點在**同一堂課的後面**要換個角度再考一次，使用者自己答出來才算推出來。

## 0. 準備（不要給使用者看答案）

- `sessions/` 裡有這個主題 `status: in-progress` 的紀錄 → 讀它，從「下一步」接著做，不要重來。
- `cards/<主題>.md` 已經存在 → 改跑 `/review`。
- 這是新主題 → 看 `index.md`「進行中」：已經 3 條 → 提醒使用者「想開第 4 條，先把一條學到告一段落」，讓他決定。
- 判斷 `type`（概念／技能／觀點）和 `maps`，不確定就問使用者。
- 在 `raw/` 找相關來源。沒有就找原始來源，存進 `raw/papers/`（網址、作者、日期、關鍵摘錄）。
- 多個來源說法不同 → 記下來，第 2 步要問使用者怎麼看（不替他裁決）。
- 自己先列出這個主題的 3～5 個關鍵點，當作考官的答案卷。**不告訴使用者。**

### 依 type 調整後面的步驟

- **概念**：照第 1～6 步。
- **技能**：第 3 步改成「講出步驟」，第 4 步改成「什麼時候要實際做一次？做完把紀錄放進 `practice/` 或給連結」。
  兩件都完成才算過；只講得出來 → `status: learning`，`next_review` 排在約定實作日之後。
- **觀點**：第 2 步重點是挖前提和反例；第 3 步改成「用你的話寫下你的看法」；
  第 4 步改成「什麼事情發生，會讓你改變這個想法？」。沒有對錯，`status: holding`，`next_review` 90 天後。

## 1. 你先寫

問：「用一兩句話，寫你現在怎麼理解 <主題>。對錯都沒關係。」
記下原話，這是起點。

## 2. 蘇格拉底

- 只問不答。從使用者的起點出發，一題一題往答案卷的關鍵點推。
- 問法：「為什麼？」「有沒有反例？」「如果 X 變了，會怎樣？」「這個前提一定成立嗎？」
- 同一個點卡住兩次 → 給一個方向提示（不是答案）。
- 使用者答對時，偶爾反問一句「你確定嗎？那 X 呢？」，答對的也要守得住。
- **不誇**：不說「好棒」「對 👍」。對就說哪裡對；不對就說「不對，如果 Y，為什麼會 X？」。
- **課中回頭考**：推到第 3 個關鍵點以後，不預告地再問一題前面已經過的點（換個情境）。答不出來 → 那個點算沒推出來，回去補。
- 記下每個卡住的點和使用者當時的想法。
- 答案卷上的點都被使用者自己推出來，或已經卡住提示過 → 進下一步。

## 3. 費曼（第一關：講解）

問：「假設我是完全不懂的朋友，用白話講給我聽。不要用術語，用了就要解釋。」
- 扮外行人挑毛病：哪裡跳步、哪個詞沒解釋、哪個說法跟 `raw/` 對不上（附出處）。
- 讓使用者自己改，直到沒有問題 → 講解 pass。改三輪還不行 → fail，記下原因，回第 2 步。
- **剛提示過的不算過**：AI 剛給提示、剛講答案、或把使用者講過的話排好給他看，下一則他照著講，這輪不算 pass。
  要中間隔至少一題別的問題，使用者再自己講一次，才算 pass。
- 不幫使用者加功勞：他沒講出來的點，不能因為「前面好像講過」就算他會。

## 4. 應用題（第二關）

出一題使用者**沒看過**的題目：情境判斷、預測、或計算。剛提示過的不算過（同第 3 步）。
- 對照答案卷和出處判斷。錯了就問「你是怎麼想的？」讓使用者自己找到錯在哪。

## 5. 存檔

- 寫 `cards/<主題>.md`（格式見 `AGENTS.md`）：
  - 「我的白話解釋」＝第 3 步最後版本的**原話**。
  - 「我做過的題目」＝第 4 步的題目＋使用者的答案原話。
  - 「我曾經搞錯的地方」＝請使用者用一句話寫，照抄。
  - 「相關的卡」＝連到既有卡片 `[[...]]`。
- 排 `next_review`（規則見 `AGENTS.md`）。
- 寫 `sessions/YYYY-MM-DD-<主題>.md`：起點原話、卡住的點、提示了什麼、兩關結果。
- 更新每個 `maps/<領域>.md` 的卡片清單（沒有就照 `AGENTS.md` 格式建）；
  「我目前的理解」是空的 → 邀請使用者寫一兩句，照抄。
- 來源是書 → 在 `raw/books/<書名>/_book.md` 的「從這本書學出的卡」加連結。
- 更新 `index.md`（存卡了就從「進行中」移掉），往 `log.md` 加一筆。
- **中途停下（還沒存卡）**：`sessions/` 紀錄寫 `status: in-progress` 和「下一步」，
  `index.md`「進行中」寫成 `- <主題>（<領域>）— 下一步：…（sessions/<檔名>）`，再 commit。
- commit 並 push。

## 6. 收尾

告訴使用者：兩關結果、下次複習日期、這次最大的漏洞是什麼。
問一句：「這個漏洞，你覺得當初為什麼會漏掉？」答案寫進 session 紀錄。
