# /review

先讀 `AGENTS.md` 的鐵則。

1. 用台灣時間今天的日期，找出 `cards/` 裡 `next_review` ≤ 今天的卡。沒有就說「今天沒有要考的」，結束。
2. 告訴使用者有幾張，一張一張考。**不要先給使用者看卡片內容。**
3. 每張卡依 `type` 考（標準見 `AGENTS.md`「三種卡」）：
   - **概念**：講解「用白話講一下 <主題>」，對照卡片和 `sources` 挑毛病；再出一題**跟卡片裡做過的不一樣**的應用題。兩關都過 → pass。
   - **技能**：「最近有做嗎？拿紀錄來。」有 `practice/` 紀錄或外部連結 → pass；沒有 → fail。
   - **觀點**：「最近有沒有發生會讓你改變想法的事？」沒有 → `holding`；有 → 請使用者重寫看法（照抄），改 `revised`，在 session 記下為什麼改。
4. 考完才給使用者看他原本卡片上寫的內容，問：「跟你剛剛講的比，差在哪？」
5. 更新卡片 frontmatter：`tests` 加一筆、`next_review` 照 `AGENTS.md` 規則排、30 天那次過了就改 `status: passed`。
   fail 時，請使用者用一句話寫錯在哪，照抄進「我曾經搞錯的地方」。
6. 往 `log.md` 加一筆，commit 並 push。
7. 最後報告：考了幾張、過幾張、下一批是哪天。
