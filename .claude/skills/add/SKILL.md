# /add <書名或連結或貼上的文字>

先讀 `AGENTS.md` 的鐵則。這一步只收來源，不學、不摘要給使用者讀。

1. **先問：「用一句話講，你為什麼想存它？」** 沒有答案就不存，跟使用者說「想到再存」。
   照抄原話。
2. 判斷類型，建檔：
   - **書** → `raw/books/<書名>/_book.md`：
     ```markdown
     ---
     title: <書名>
     author: <作者>
     added: YYYY-MM-DD
     status: reading        # reading | done | dropped
     ---
     ## 我為什麼讀（原話）
     ## 讀到哪
     ## 從這本書學出的卡
     ```
     之後使用者讀到某章，給重點或拍照 → 存成 `raw/books/<書名>/chNN.md`（照抄使用者給的內容，註明頁碼）。
   - **文章** → `raw/articles/YYYY-MM-DD-<短名>.md`：網址、作者、發文日期、**全文**、我為什麼存。
     抓不到（FB、Threads 要登入）→ 請使用者貼全文或截圖，不要只存連結。
   - **論文／官方文件** → `raw/papers/<短名>.md`：網址、作者、年份、摘錄、我為什麼存。
3. 問：「這跟哪個領域有關？」列出 `maps/` 現有的領域讓使用者選，也可以新的（新的等第一張卡出現才建地圖頁）。
4. 問：「裡面有沒有一個概念你現在就想 `/learn`？」
   - 有 → 直接開 `/learn <概念>`，`sources` 帶上這個檔。
   - 沒有 → 把來源加到 `index.md` 的「待讀來源」。
5. 往 `log.md` 加一筆：`## [YYYY-MM-DD] add | <來源名> | <類型>`，commit 並 push。
